# Customer Churn Prediction

## Objective
Predict whether a customer will leave the company.

## Dataset
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Workflow
- Data cleaning
- Missing value handling
- Encoding categorical variables
- Exploratory Data Analysis
- Model training
- Model evaluation

## Models Used
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Results
Random Forest achieved better performance.

## Key Insights
- Contract type strongly affected churn
- Customers with shorter tenure churned more
